Developer observability for AI coding agent sessions

Usage:
  peasant [flags]

Available Commands:
  annotate    Manage session and project annotations
  completion  Generate the autocompletion script for the specified shell
  config      Edit peasant configuration
  export      Export session data, annotations, and schemas
  harvest     Harvest AI coding agent transcripts
  help        Help about any command
  kickstart   Run the first-time setup wizard
  metrics     Manage session metrics
  migrate     Convert file-backed sessions to the harmonized content model
  models      Manage model reference data
  open        Record one session and open its transcript in the web dashboard
  prune       Remove sessions from local store and database
  reclaim     Reclaim superseded managed generations (rows and blob directories)
  redact      Redact local transcripts
  sessions    Manage sessions
  upgrade     Upgrade Peasant
  version     Print the version
  village     Interact with peasant online
  web         Launch the web dashboard

Flags:
      --config string       Path to config file (default: ~/.config/peasant/config.yaml) (default "/home/hatch/.config/peasant/config.yaml")
      --config-dir string   Override the config directory (default: $XDG_CONFIG_HOME or ~/.config); config lives under <config-dir>/peasant
      --data-dir string     Override the data directory (default: $XDG_DATA_HOME or ~/.local/share); the DB + peasant-sync live under <data-dir>/peasant
  -h, --help                help for peasant
      --state-dir string    Override the state directory (default: $XDG_STATE_HOME or ~/.local/state); logs/PID live under <state-dir>/peasant
  -v, --version             Print the version

Use "peasant [command] --help" for more information about a command.
